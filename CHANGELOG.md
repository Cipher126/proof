# Changelog

## 0.1.0

First local portfolio release.

- Guided reconciliation console with journal inspection, an event trail, and audited settlement closure.
- PostgreSQL ledger, idempotent transfers, expiring holds, capture fees, and partial or full refunds.
- Signed simulated provider events, settlement imports, discrepancy detection, and at-least-once HTTP outbox delivery.
- Scoped API credentials, sandbox admission limits and opt-in retention, plus local monitoring and optional trace export.
- Docker Compose, generated OpenAPI, a runnable demo smoke check, and deployment and recovery guides.
